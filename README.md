# JavaScript Master: Next.js series

Source code for the **JavaScript Master** YouTube series: a weekly Next.js tutorial that takes you from zero to advanced, one Friday at a time. Every episode builds on the same app, **JM Notes**.

Each episode lives in its own folder. Open the folder, run `npm install`, then `npm run dev`.

| 3 | Arrays, Objects & Async JS | [ep03-arrays-objects-async](ep03-arrays-objects-async) | [Watch on YouTube](https://www.youtube.com/watch?v=2aIZkbgVXqQ) |
